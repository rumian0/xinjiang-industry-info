## 四、调研结论

1. **新疆政府网站几乎不提供标准 RSS**（`list_rss.shtml` 是说明页，非 XML feed），政务 CMS 统一用「大汉版通」列表页（`list.shtml`），可用 `list` 方式稳定解析。
2. **企业官网详情页多为 JS 渲染**，但首页/列表页的标题可静态抓取，作为真实采集内容足够。
3. **媒体类（天山网、石榴云）普遍 JS 渲染**，需要 Playwright，属于「必要时才用」的场景，留待后续。
4. **招投标平台**（兵团、自治区公共资源交易网）信息价值高，但反爬/动态结构复杂，首页聚合可作为轻量接入点。
5. 现有采集器已支持 `rss` / `list`（政务 CMS）/ `generic`（企业官网通用列表）三种方式，新增来源只需改配置，无需改代码（个别特殊结构除外）。
